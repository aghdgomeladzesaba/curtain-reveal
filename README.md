# Curtain Reveal

An interactive React application combining animated curtains, dramatic audio effects, customizable themes, and multilingual support to create a theatrical reveal experience.

Created as a Mobile Web Development project at Pace University.

## About the Project

Curtain Reveal is an interactive website where users can play a mysterious audio message and watch animated curtains open to reveal a vintage newspaper image.

I wanted to make the experience more engaging by combining visual effects, sound, and customization. Users can change the appearance of the website, switch between languages, and select different computer voices for the final message.

## Features

- Animated curtains that open after the audio finishes
- Audio playback with a reverb effect
- Computer-generated speech using the Web Speech API
- Voice selection with preferences saved in the browser
- Four customizable themes: Dark, Light, Matrix, and Barbie
- English and Russian language options
- Home, Settings, About, and Help sections
- Custom CSS animations and styling

## Technologies Used

- React
- JavaScript
- Vite
- Mantine UI
- CSS
- Web Audio API
- Web Speech API
- Tuna.js

## How to Run the Project

Make sure Node.js and npm are installed.

1. Clone or download the repository.
2. Open the project folder.
3. Install dependencies:

   `npm ci`

4. Start the development server:

   `npm run dev`

5. Open the local URL displayed in the terminal.
